FSR 3.1 and FSR 4 are upscaling options that can help a wide range of graphics cards. They are useful when you want better performance without lowering the game’s visual style too much. XeSS is designed for Intel graphics and can also work on some other supported hardware. DLSS is made for NVIDIA graphics cards and can provide strong image quality with performance savings.

Frame generation is a separate option that can make movement feel smoother by adding extra frames. It works best when your base performance is already steady. If the game feels responsive enough, you can leave frame generation off. If you want smoother motion and your hardware supports it, turn it on and compare the result.
